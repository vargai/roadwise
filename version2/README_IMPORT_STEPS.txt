Google My Maps import guide for Norway fjord road trip CSV layers

Import suggestions:
1. Go to https://mymaps.google.com and create a new map.
2. Add/import one CSV per layer. Choose Address as the location column and Name as the title column.
3. Google My Maps has a limited number of layers. If you hit the limit, use 00_All_Stops_Master.csv instead, or merge optional layers.
4. CSV files import points only. To show an actual driving route, import the relevant Route Day CSV as points, then click Add directions in My Maps and enter the same stops in Order order.
5. For live navigation, open each daily route separately in regular Google Maps.

Recommended priority colors:
Must = red
Recommended = blue
Alternative = gray
Optional = light gray
Weather dependent = purple
Safest = green

This file set is based on the relaxed July itinerary:
Night 1-2 Aurland/Flam/Gudvangen
Night 3-5 Loen/Olden/Stryn
Night 6 Voss or Bergen Airport area
Day 7 Bergen Airport by noon
